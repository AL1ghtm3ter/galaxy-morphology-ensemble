# 方法与评估口径

## 任务定义

Galaxy Zoo挑战数据提供37个连续目标，表示志愿者对不同星系形态问题的投票比例。它们对应11组问题，输出维度分别为：

```text
3, 2, 2, 2, 4, 2, 3, 7, 3, 3, 6
```

数据列顺序集中定义在 `src/galaxy_morphology/tasks.py`。这是一组回归目标；“根节点准确率”只对前三个输出取argmax，不是37类分类准确率。

## 模型

ViT-B/16、Swin-T和EfficientNet-V2-S分别使用ImageNet预训练参数。移除原分类层后，每个骨干连接11个独立线性头，拼接成37维输出。

这种分组保留了问题组织方式，但没有显式计算父子条件概率，也没有强制各组输出归一化。不能把整体均值接近某个数值解释为逐样本概率约束已满足。

## 训练配置

完整配置位于 `configs/baseline.json`。

| 参数 | ViT / Swin | EfficientNet |
| --- | --- | --- |
| Epochs | 15 | 15 |
| 微批次大小 | 8 | 8 |
| 梯度累积批次 | 4 | 4 |
| 优化器 | AdamW | AdamW |
| 初始学习率 | 8e-5 | 5e-5 |
| Weight decay | 0.05 | 0.01 |
| 学习率调度 | 余弦退火 | 余弦退火 |
| 损失 | MSE | Huber，delta=0.1 |
| 梯度裁剪范数 | 1.0 | 1.0 |

训练集使用随机旋转、水平/垂直翻转、224像素中心裁剪和ImageNet归一化。验证集只做确定性的裁剪与归一化。

## 集成与TTA

每张图使用原图、水平翻转、垂直翻转、90°和180°旋转，先对同一模型的五个预测取平均，再计算：

```text
prediction = 0.55 × ViT + 0.30 × Swin + 0.15 × EfficientNet
```

命令行工具要求多个检查点保存的验证ID及顺序完全一致，避免把不同数据划分的模型结果混合成同一项验证成绩。

## 指标

- **全局RMSE：**全部样本和37维目标上的均方误差开平方。
- **分任务RMSE：**只在该问题对应的目标维度上计算。
- **根节点准确率：**比较前三维预测与标签各自的argmax。
- **R²：**分别计算各输出维度的决定系数，再均匀平均。
- **Pearson与余弦相似度：**逐图像比较37维向量后取均值。

## 记录与复现的区别

`results/` 保存2026年4月原Notebook输出中的指标；图表脚本仅重画这些记录。原训练随机划分使用seed 42，验证集同时用于检查点选择和模型比较，因此结果不是独立测试评估。

模块化CLI保留模型、目标、主要超参数、TTA与融合权重，并增加了明确的随机种子、检查点元数据、不可读图像报错及正确的梯度累积尾批归一化。它属于后续整理实现，不承诺与原Notebook逐位等价。新运行的指标应单独报告。
